O Projeto

O DevBlog nasceu como um projeto prático do curso de Python. A ideia é construir, do zero, um blog completo usando o framework Django, passando por rotas, views, templates e banco de dados. Mais do que publicar artigos, o objetivo é entender, na prática, como uma aplicação web é estruturada e como cada peça se encaixa.

O que estamos construindo

  • Rotas e Views: mapeamento de URLs para as funções que respondem cada página.
  • Templates: herança de layout com o sistema de templates do Django.
  • Banco de Dados: modelagem dos artigos e integração com o ORM do Django.
